# Milestone v1 — CI release approval gate

Date: 2026-11-25

## Baseline and substantial delta

Baseline: [`3f0657274df1170546ece76b9501f4e3303a7f21`](https://github.com/ANZA24k/ReleaseGate/commit/3f0657274df1170546ece76b9501f4e3303a7f21),
the latest repository state before this work. Explorer acceptance metadata is not in
the repository, so this identifies the repository baseline, not a verified acceptance timestamp.

| Before | Added in milestone v1 |
| --- | --- |
| Human inspection in read-only portal | CLI and reusable GitHub composite action enforce approval in release pipelines |
| No binding to the build being deployed in CI | Mandatory contract, project, release, owner, repository, full commit, version and policy pins |
| No consumer-side decision verification | Deployed source identity, finalized reads, repeat snapshot check, policy rehash, revision validation, outcome/score recomputation |
| No portable CI decision record | Atomic canonical-hash approval/denial receipts and offline integrity audit command |
| No gate regression coverage | Adversarial unit/integration/CLI tests and Python contract parity over 486 outcome combinations |

This adds a new integration consuming the accepted contract's decisions. No new
contract deployment, consensus transaction, production use, or adoption is claimed.

## Implementation

- [CLI](../scripts/release-gate.mjs): identity pins, exit codes, atomic receipt writes and stale-output removal.
- [Verifier](../scripts/lib/gate.mjs): policy, identity, revision, evidence and deterministic aggregation checks.
- [Live adapter](../scripts/lib/live-gate.mjs): real finalized GenLayerJS reads, deployed source verification and bounded operations.
- [GitHub action](../action.yml) and [live regression workflow](../.github/workflows/gate-integration.yml).
- [Integration guide](CI-GATE.md) and [adversarial tests](../tests/gate/).

## Validation and limits

Commands: `npm test`, `npm run build`, `python -m pytest tests/direct -q`,
`genvm-lint check contracts/release_gate.py --json`, and
`node scripts/check-repository.mjs`. Results: [validation.json](milestone-v1/validation.json).

The gate trusts Studionet RPC and local time. Receipt hashes establish internal
integrity only; offline checking never authorizes a deployment. The integration
does not re-run AI consensus or authenticate original reports. The existing portal
is unchanged; the action and CLI are the new functionality.
